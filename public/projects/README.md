# Images des projets

Déposez ici les captures de vos projets (WebP, JPG, PNG ou AVIF).
Format conseillé : 1600 × 1200 pixels, idéalement moins de 500 Ko.
Nom simple : `mon-projet.webp` (sans espaces ni accents).

Dans data/projects.json, utilisez `/projects/mon-projet.webp` comme valeur de `image`.
Ne mettez pas de captures contenant des données clients confidentielles.
